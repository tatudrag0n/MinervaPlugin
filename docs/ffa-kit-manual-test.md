# FFA Kit Manual Test

対象: MinerVa FFA 常設キット

## 前提

- Paper API / Minecraft は `pom.xml` の `paper-api 26.1.2.build.12-alpha` 対応サーバーを使う。
- `plugins/` に今回ビルドした MinerVa jar を入れる。
- 必要に応じて `config.yml` の `ffa.center` と `ffa.kit-selection` を設定する。
- `/mva ffa createkits` でキット選択防具立てを作成する。

## 確認手順

1. `/mva ffa reload` を実行し、エラーが出ないことを確認する。
2. キット選択 GUI に以下9種だけが表示されることを確認する。
   - ソードマン
   - ウォリアー
   - アーチャー
   - スピアー
   - リボルバー
   - シールダー
   - ウィザード
   - トライデント
   - メイス
3. 各キットを選び、装備・食料・エンチャントが `config.yml` のデフォルト通りに配布されることを確認する。
4. `ffa.stands.selected-kit` に存在しないIDを入れて再読み込みし、ソードマンにフォールバックすることを確認する。
5. FFA参加中に死亡し、同じキットで再出撃し、消耗品が初期数に戻ることを確認する。
6. `/mva ffa leave` で参加前のインベントリ、体力、食料、ゲームモード、スコアボードが戻ることを確認する。
7. FFAワールド外へ移動し、`ffa.world-change.leave-on-exit: true` の場合だけ退出復元されることを確認する。
8. FFAアイテムをドロップ、容器へ収納、クラフト材料へ使用、額縁へ設置できないことを確認する。
9. ウォリアーで移動速度低下Iが常時付与され、退出・キット変更後に残らないことを確認する。
10. ウィザードで自分が投げた負傷・毒・鈍化ポーションを自分だけ受けず、他人のポーションは受けることを確認する。
11. ウィザードのスプラッシュポーションを連打し、3秒クールダウンとアクションバー表示を確認する。
12. リボルバーで6発撃てること、表示が `6/6` から減ること、撃ち切り後に約75tickのリロード音と復帰があることを確認する。
13. リボルバー弾の対プレイヤーダメージが通常クロスボウのおよそ70%になることを比較確認する。
14. トライデントを投げ、忠誠IIIで戻ること、他人が拾えないこと、退出・死亡・キット変更時に残留トライデントが消えることを確認する。
15. メイス攻撃で対プレイヤー最終ダメージが12HPを超えないことを確認する。
16. `/minerva`、`/mva`、`/friend`、`/friends`、`/status` が従来通り登録され、`/mv` が MinerVa に登録されていないことを確認する。
